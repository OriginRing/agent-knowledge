# 管理端说明

管理端独立运行于 `admin/`，默认端口 5174，仅允许管理员登录。启动：`cd admin && npm ci && npm run dev`。`ADMIN_API_TARGET` 可指定开发代理后端，默认 `http://127.0.0.1:8000`。

## 最新配置与发布

不提供历史版本管理、版本选择或回滚。Skill 同名上传替换当前配置，工作流保存即更新当前配置。智能体保存草稿后需点击发布，发布时读取最新工作流与 Skill 并校验。修改工作流或 Skill 会将引用它们的智能体标记为“待重新发布”并下线；重新发布前不接受新对话。已开始的请求继续完成，历史对话保留。

每种资源只保留一份当前发布记录；修订号仅用于并发编辑校验和缓存失效。启动时清理旧历史配置记录，检查旧发布配置是否需要重新发布。执行中的 Skill 文件暂留以保证请求完成。

## 工作流

节点支持开始、模型、Skill、条件、结束，无循环和并行。模型继承智能体配置。输入引用 `{{input.text}}`、`{{input.files}}` 和 `{{nodes.model.output.text}}`；Skill 参数可引用上游结构化结果。Skill 的非空 `context` 自动传给后续模型，结束节点指定最终回答和产物。非法草稿可保存，但智能体不能发布。工作流调试选择智能体草稿，不写正式对话历史。

## Skill

ZIP 包包含 SKILL.md、Python 入口及资源文件。限制 20 MB 压缩大小、50 MB 解压大小及 500 个条目；拒绝越界、链接、重复路径、加密包。上传不执行代码、不安装依赖。内置 Skill 只读；上传 Skill 同名替换。存在工作流、智能体或运行请求引用时禁止删除。执行仍校验智能体范围与用户业务权限。

## 删除

智能体必须下线后删除，未发布草稿可直接删除。工作流显示使用智能体数，按当前草稿和当前发布配置去重；仅 0 个智能体使用时允许删除。删除保留历史标识，避免重启恢复及编号复用。

## 知识库

文件上传、URL 导入、检索和清空统一在管理端 `/knowledge`，对应 `/admin/knowledge/file`、`upload`、`search`、`clear`。清空需二次确认。用户端保留对话知识库能力，旧管理入口和接口已移除。沿用原解析、存储和服务配置。
